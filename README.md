# Cascade

A living waterfall you compose in the browser.

**Play in the browser — nothing to install:**  
https://drewarrowood.github.io/cascade-waterfall/

Tune flow, width, drop, wind, mist, season, weather, and hour of day. The gorge answers with water, light, and sound.

Same hosting as [orrery](https://github.com/drewarrowood/orrery): plain files on `main` (`docs/`), GitHub Pages, no server.
