# Cascade

A living waterfall you compose in the browser.

**Play in the browser — nothing to install.**

https://drewarrowood.github.io/cascade-waterfall/

Tune flow, width, drop, wind, mist, season, and hour. The gorge answers with water, light, and sound.

Same model as [orrery](https://github.com/drewarrowood/orrery): plain files on `main` (`docs/`). No server. No npm. No app to install.

## Turn on public hosting (one time)

1. Open https://github.com/drewarrowood/cascade-waterfall/settings/pages
2. **Build and deployment**
   - **Source:** GitHub Actions
   - Save if asked
3. Wait about a minute. Visit https://drewarrowood.github.io/cascade-waterfall/
